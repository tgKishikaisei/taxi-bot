# Безопасность

## Как сообщить об уязвимости

Не открывайте публичный issue. Нажмите «Report a vulnerability» на вкладке **Security** или напишите мне в Telegram: [@BehruzAvezmatov](https://t.me/BehruzAvezmatov).

## Что сделано

- Имя, марка, номер машины и адрес экранируются перед отправкой с `parse_mode=HTML`, поэтому водитель не подставит пассажиру свою ссылку.
- Фото машины сохраняется в `photos/<tg_id>/`: имя пользователя в путь не попадает.
- Бот принимает только собственный контакт пользователя, пересланный чужой отклоняется.
- Заказ берётся одним атомарным `UPDATE ... WHERE`, SQL-запросы параметризованы.
- Токен, пароль базы и ключ геокодера берутся из `.env`; URL с ключом в лог не попадает.

GitHub Actions на каждый push запускает тесты, `pip-audit` и `gitleaks` по всей истории.
